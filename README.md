# 观潮 · 回声社区观察台 v14

React 数据可视化课程原型，面向虚构单平台“回声社区”。观察当前流量分布、话题中的事件、观点与情绪变化。**所有内容、流量、观点、情绪和语料均为合成演示数据，不是真实平台记录。**

## 三个进程

```
[corpus producer :5400]  --/feed SSE-->  [system :5300]  --/api/stream-->  [React]
 预生成 7 天语料 + 聚合回填            摄取 / 加权 / 聚合 / 缓存          总览 / 详情 / 讨论
```

- **外部语料生产者**：`corpus/` 目录，独立进程与独立端口，持有约 700 万条预生成文本；主应用通过 HTTP/SSE 消费。它不属于系统本体，只负责输送。
- **系统**：Vite 开发服务内的 `/api/*`，把文本流聚合成 5 秒 / 5 分钟 / 1 小时计数，持久化聚合，向浏览器推送快照与 SSE。
- **前端**：总览气泡、观点/情绪双环、讨论列表、单词树、底部流量图。

## 快速开始

```bash
npm install
npm run corpus:build          # 全量：7 天 / 约 700 万条 / 约 110 个话题
# 或快速开发：node corpus/build.js --days 1 --total 20000
npm run dev:all -- --port 5300
```

也可以分两个终端：

```bash
npm run corpus:serve          # 生产者，默认 127.0.0.1:5400
npm run dev -- --port 5300    # 系统 + 前端
```

生产者默认读 `corpus/out`，可用 `CORPUS_URL` 指定其它地址。`corpus/out/` 与 `server/.data/` 不入库。

## 数据模型（简版）

- **7 天滚动窗口**：话题、聚合与语料统一保留 7 天，代码里由 `RETENTION` 常量控制。
- **三层实体**：主帖 → 评论 → 回复。评论不等价于主帖；三者有独立指标与权重。
- **指标口径**：主帖有浏览、点赞、转发、评论数；评论/回复有点赞、回复数；评论曝光是内部潜变量，**API 与界面都不返回**。
- **互动权重**：主帖用互动率/浏览，评论/回复用点赞/内部曝光，各自做贝叶斯收缩后映射为 0–100；环形、条形、词云、讨论都使用加权计数。
- **情绪**：DUTIR 大连理工情感词汇本体库 7 大类 21 小类 + 无显著情绪；外环显示 Top 8 小类 + 其他。
- **语料驱动**：观点/情绪计数来自实际摄取的文本，Beta 脉冲只负责浏览量曲线。
- 公式、字段、比例与来源见 [DATA.md](DATA.md)。

## 界面

总览气泡面积仍严格正比于每分钟曝光。详情页为：

- 左侧大圆：圆内全横向词云（观点色）；内环 5 类观点；外环 Top 8 情绪 + 其他。
- 右侧三页签：**观点**（互动加权条形 + 原始讨论量 tooltip）、**讨论**（主帖卡 + 评论/回复树 + 0–100 权重条 + 21 情绪筛选）、**词树**（前后文，点击词语重定根）。
- 底部聚焦流量图与事件标记不变；窄屏右侧面板收为底部抽屉，保留三页签。

点击内环或外环可同时叠加观点/情绪筛选；词云、讨论与词树从筛选后的语料重算。语料源离线时环形/条形仍显示已缓存聚合，文本区标注“语料源离线”。

## 测试与构建

```bash
npm test          # 54 项：生命周期、语料、权重、聚合、API/SSE、布局
npm run build     # dist/client + dist/server/index.js Worker
```

生产 Worker 是纯浏览器平台产物，不包含 Node 摄取器；它使用分析回退，文本相关接口返回空并在界面标注。完整语料演示需运行外部生产者。

## 开发调参台

开发服务左下角“动画 / 布局调参”；生产默认隐藏，`?tune=1` 显示。新增“语料 / 讨论”组与情绪环几何参数；改动实时生效并保存在 localStorage，可恢复默认、复制 JSON、重播舞台。

验证辅助（仅开发期）：`?qa=1` 强制气泡布局（后台标签页截图用），`?reduced=1` 跳过入场动画，便于静态核对。生产不受影响。

## 目录

- `corpus/`：句式库、确定性生成器、生产者、聚合导出。
- `shared/`：话题实例、生命周期、DUTIR、权重、词树、旧词云工具。
- `server/`：`mock.js` 话题/事件、`aggregator.js` 摄取聚合、`runtime.js` 开发运行时、`api.js` 纯 API、`corpus-client.js` 生产者客户端。
- `src/`：总览、详情舞台、讨论、词树、图表、调参。
- `tests/`：54 项自动测试。

本版把旧版“120 天 + 客户端 600 条/小时模板语料”替换为“7 天 + 外部 700 万条三层语料”。不接真实平台、不爬取、不使用真实用户或事件。
