# 观潮 · 回声社区观察台 v13

React 数据可视化课程原型，面向虚构单平台。观察当前流量分布、话题中的事件与主流观点变化。内容、流量、观点和语料均为合成演示数据，不是真实平台记录。

## 使用

气泡面积正比于每分钟新增曝光，固定绝对比例尺，不限制最小/最大数据半径。拖动画布平移，滚轮或双指缩放；“查看全貌”只调整统一镜头。小话题使用两侧书签卡片，折线末段水平接入，可点击、放大、悬停或搜索定位，点击进入详情。仅在“现在”模式开启水滴凝聚汇流，历史回看关闭；气泡优先显示话题名称，数值缩小为辅助信息，不在数值后重复单位。

总览以气泡画布为主体，观潮标识和搜索框悬浮在画布上。已移除总览的曝光总数、排行切换及演化图下方的图例和说明，演化图压缩在画布下方。圆之间的世界间隔随较小圆半径增加。首次排布根据视口宽高比选址，横屏利用横向空间；随后固定话题圆心，拖动时间只更新半径，新话题也不会推动原有气泡；窗口尺寸变化时重新适配镜头，用户仍可自由缩放拖动。

下方流量演化图就是全局时间控制。左键拖动图表定位时刻，滚轮缩放视野，底部滑动条平移时间轴，回到现在恢复实时跟随；键盘左右键定位时刻，Shift+左右键平移。独立底部播放器已删除。

观察范围支持1小时、1天、7天、30天、全部120天历史。实时数据持续接收，回到现在即追上最新时刻。

详情依次是流量大图、事件节点、内容、观点条形图与观点河流、词云与代表评论。上下时间图完全同步，默认首事件贴左；已结束话题可选完整生命周期，额外1小时供讨论滑动窗口排空。搜索包含历史话题，打开已过期话题会定位到生命周期内。

## 模型与开发

120天历史约每天一个独立话题，24种虚构模板按日期区分。寿命4小时至28天，多个事件冲击形成多峰；开始和结束曝光率为零，平台时间持续延伸。模型与来源见 DATA.md。

`npm install` → `npm run dev`；`npm test`；`npm run build`。开发服务同时提供 `/api/snapshot` 和 `/api/stream`。生产输出 dist/client 与 dist/server/index.js Worker。

shared/catalog.js 定义模板；shared/lifecycle.js 提供速率及解析积分；server/mock.js / api.js 为快照与SSE；src/live.js 接流和统一时钟；src/bubble-world.js 为映射、无边界布局和镜头；src/charts.jsx / main.jsx 为界面。

详情页“关于观潮”可下载五份项目说明。旧的两小时数据、底部播放器、矩形容纳气泡布局已替换。
