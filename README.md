# 观潮 · 回声社区观察台 v13

React 数据可视化课程原型，面向虚构单平台。观察当前流量分布、话题中的事件与主流观点变化。内容、流量、观点和语料均为合成演示数据，不是真实平台记录。

## 使用

气泡面积正比于每分钟新增曝光，固定绝对比例尺，不限制最小/最大数据半径。拖动画布平移，滚轮或双指缩放；“查看全貌”只调整统一镜头。小话题使用贴近气泡的附属书签卡片，位置灵活避让，折线末段水平接入，可点击、放大、悬停或搜索定位，点击进入详情。仅在“现在”模式开启水滴凝聚汇流，历史回看关闭；气泡优先显示话题名称，数值缩小为辅助信息，不在数值后重复单位。

总览以气泡画布为主体，观潮标识和搜索框悬浮在画布上。已移除总览的曝光总数、排行切换及演化图下方的图例和说明，演化图压缩在画布下方。圆之间保留适度留白，按当前半径紧凑排布。时间拖动时逐帧修正碰撞，同时减慢整体整理；大圆偏向中心、小圆偏向外围，以限速和阻尼缓慢收拢；不再为历史峰值保留大空隙，也不按流量排序重新打散布局。窗口尺寸变化时适配镜头，仍支持自由缩放拖动。

下方流量演化图就是全局时间控制。左键拖动图表定位时刻，滚轮缩放视野，底部滑动条平移时间轴，回到现在恢复实时跟随；键盘左右键定位时刻，Shift+左右键平移。独立底部播放器已删除。

观察范围支持1小时、1天、7天、30天、全部120天历史。实时数据持续接收，回到现在即追上最新时刻。

点击气泡后，气泡放大并移动到中部靠左，圆内浮现全部横向的词云，外圈环形显示当前舆论占比；右侧默认观点条形图，悬浮词显示该词的前后文单词树，悬浮环形扇区高亮对应排行。下方流量图聚焦到该话题并放大，事件节点保留为图上标记与悬浮卡；原详情的事件轨道、观点河流、旧词云和评论取消。转场、底部视口滑动条和“现在”沿用总览。搜索包含历史话题，打开已过期话题会定位到生命周期内。

## 模型与开发

120天历史按每90分钟一个新话题生成，40类现实议题与80座城市组合成唯一标题，同一原型不会同时在榜；累计曝光低于500万的话题不入库。寿命8至60小时，多个事件冲击形成多峰；开始和结束曝光率为零，平台时间持续延伸。同时在榜通常为8至23个话题。模型、公式与来源见 DATA.md。

`npm install` → `npm run dev`；`npm test`；`npm run build`。开发服务同时提供 `/api/snapshot` 和 `/api/stream`。生产输出 dist/client 与 dist/server/index.js Worker。

shared/catalog.js 定义模板；shared/lifecycle.js 提供速率及解析积分；shared/corpus.js 确定性生成近1小时模拟文本，供观点筛选、词云和单词树使用；server/mock.js / api.js 为快照与SSE；src/live.js 接流和统一时钟；src/bubble-world.js 为映射、无边界布局和镜头；src/charts.jsx / topic-stage.jsx / word-tree.jsx / topic-page.jsx / main.jsx 为界面；src/tuning.js / tuning-panel.jsx 为开发调参台。

## 开发调参台

开发服务左下角有“动画 / 布局调参”按钮；生产构建默认隐藏，在网址后加 `?tune=1` 才显示（面板代码单独打包，不影响主包首屏）。面板分为转场·入场时序、舞台·气泡与词云、舞台·环形与圆、底部流量图、页面布局·桌面、页面布局·窄屏、单词树、图标八组，共 93 项滑杆、数字框与缓动下拉。

改动实时生效并自动保存在本机 localStorage；数字框可精确输入，滑杆便于快速试探；“恢复默认”清除覆盖值，“复制 JSON”导出当前全套参数，“重播舞台”让词云、环形和标题重新入场。FLIP 飞行、底部图表三阶段聚焦、顶栏/面板淡入属于进入话题时的时序，需要返回总览重新进入话题预览。该面板只改变视觉尺寸、布局和动画时序，不参与数据生成或计算。

详情页“关于观潮”可下载五份项目说明。旧的两小时数据、底部播放器、矩形容纳气泡布局已替换。
